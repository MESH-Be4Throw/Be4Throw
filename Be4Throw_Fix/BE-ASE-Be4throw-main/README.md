# BE-ASE-Be4throw
Be4Throw adalah platform yang membantu pengguna menentukan tindakan terbaik sebelum membuang barang.
Repo ini adalah **backend** dari Be4Throw, dibangun menggunakan Express.js.

## 🚀 Tech Stack

- Node.js
- Express.js
- dotenv

## 📁 Struktur Folder

- `controllers/` 
- `models/` 
- `routes/`
- `index.js`
- `.env`
- `package.json`

## ⚙️ Cara Menjalankan Project

1. Clone repo ini
```bash
   git clone https://github.com/Baswara06/BE-ASE-Be4throw.git
```

2. Masuk ke folder project
```bash
   cd BE-ASE-Be4throw
```

3. Install dependencies
```bash
   npm install
```

4. Buat file `.env` di root folder, isi dengan: PORT=3000


5. Jalankan server (mode development)
```bash
   npm run dev
```

6. Server akan berjalan di `http://localhost:3000`
